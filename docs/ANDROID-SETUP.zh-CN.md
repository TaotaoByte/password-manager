# 安卓设置与手动同步

## 红米 K80 Pro / HyperOS（优先）

先在应用内创建或打开自己的 KDBX 密码库，再进入设置的表单填充页面，选择系统默认自动填充服务。系统设置名称随 HyperOS 版本变化；可搜索“自动填充”“密码”或“凭据”，将本应用设为首选服务。

Chrome 及其衍生浏览器可能还需在浏览器设置中选择使用其他自动填充服务。支持的键盘会在键盘上方显示账号建议，否则系统可能显示弹出候选列表。

若点击候选后无法打开密码库，检查系统是否阻止本应用在后台弹出界面；仅在确有阻止时调整对应权限。后台限制影响使用时再检查本应用的电池设置。不需要关闭 MIUI 优化或系统安全防护。

设备适配以实际安装的 Android / HyperOS 版本为准。未经过此手机实测的功能均以兼容记录为准。

## 其他安卓

- 原生安卓：在设置中搜索“自动填充服务”或“密码、通行密钥和账号”，选择本应用。
- 三星 One UI：在设置中搜索“密码”“首选服务”或“自动填充”，更改首选服务。
- OPPO / 一加 ColorOS：搜索“密码”“自动填充服务”，选择本应用。
- vivo OriginOS：搜索“密码”“自动填充”，进入系统支持的服务选择页面。

以上为设置导航指引，菜单名称可能随版本变化，不代表已完成对应品牌实机测试。

## 保存与填充限制

系统必须能够识别目标应用的登录表单，才能提供填充或保存回调。无法识别时，使用手动新增、手动选择或上游 Magikeyboard。密码管理器不会监听键盘、抓取其他应用密码，也不保证所有应用都出现保存提示。

## 手动同步

1. 两端都先保存并关闭密码库，保留本地副本。
2. 把安卓上的 `.kdbx` 文件传到 Windows 的临时接收目录，不直接覆盖 Windows 主库。
3. 在 Windows 备份主库，再使用“数据库→从数据库合并”，选择安卓副本并输入其主密码。
4. 检查条目及历史，保存合并结果；将该结果传回安卓。
5. 安卓原库另存为带日期的备份，再打开合并后的文件。

传递的始终是加密 KDBX 文件。不通过 CSV 明文中转；两端使用同一主密码时，主密码也不随文件发送。

## LocalVault 底部操作

打开密码库后，底部浮动栏提供搜索、库菜单和锁定。库菜单可打开应用设置及数据库工具，锁定按钮遵循应用中的显示偏好。浮动栏位于应用内容内，系统手势区与三键导航仍由 Android 管理。

玻璃效果随 Android 版本降级。Android 13 及以上使用模糊及弧边折射，Android 12 使用原生模糊，Android 11 使用半透明底色。有些设备关闭硬件渲染时也会使用半透明底色。
