## K80 Pro 首要验收

记录：手机型号、Android 版本、HyperOS 完整版本号、安全补丁日期、键盘版本、浏览器版本和 APK SHA-256。

1. 从系统选择本应用为自动填充服务，返回后显示已启用。
2. 测试原生登录表单及浏览器表单；分别验证一个匹配、多个匹配、无匹配。
3. 锁定密码库后请求填充，解锁成功后回到原应用；取消不写入、不填充。
4. 系统提供保存请求时，确认后新增；已有账号改密码时，确认后更新并保留历史。
5. 切换应用、锁屏再解锁、后台停留后重复以上操作。
6. 没有自动填充入口的应用使用手动选择或 Magikeyboard；记录具体应用与限制。
7. 仅在系统阻止界面打开时提示相关后台弹出权限。不关闭 MIUI 优化，不申请无关权限。

## Windows 与浏览器

- 快捷保存记录原窗口标题，确认后关联；取消、锁定取消均不新增记录。
- 快捷键冲突有提示；多账号必须能选择；填充不自动按 Enter。
- 原窗口消失或焦点不再匹配时，不把凭据输入到其他窗口。
- Edge、Chrome：注册、登录、改密、多账号、分步登录；未配对或库锁定时不泄露凭据。
- 普通权限程序不能保证向管理员窗口输入，应给出限制说明。

## 密码库互通与恢复

- Windows 新增→安卓编辑→Windows 合并，保留网址、AndroidApp 字段、窗口关联和历史。
- 两端分别新增、分别修改同一条目，再合并；验证历史和删除记录。
- 合并前建立加密备份；错误主密码、损坏输入文件不能覆盖当前库。
- 从备份恢复后能正常解锁与使用；日志不包含密码。
