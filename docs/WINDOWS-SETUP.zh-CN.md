# Windows 使用说明

这是基于 KeePassXC 的本地定制版本。解压便携包后运行 `KeePassXC.exe`。首次运行选择中文，创建 KDBX 4 密码库，设置独立且足够强的主密码。密码库放在自己的数据目录中，不放入源码仓库。

## 启动与界面

在完整项目文件夹里，双击根目录的「启动密码管理器.cmd」即可；它打开 `dist/windows/KeePassXC.exe`。`upstream`、`build`、`.tools` 是开发材料，不是另一个日常使用入口。目录说明见根目录「00-先看这里.md」。

默认采用“查看 → 主题 → 自动”，随 Windows 的应用颜色模式使用浅色或深色界面，也可在该菜单手动选择亮色／暗色。系统高对比度模式沿用上游的经典界面处理。

首页集中显示创建、打开、导入和最近的密码库；尚未打开密码库时隐藏工具栏。打开密码库后，左侧是分组，中间是账号列表，顶部是新增和搜索。最近文件只显示文件名及所在文件夹名，鼠标停留可查看完整路径；回车打开、Delete 移除最近记录，不删除密码库文件。小窗口下首页可以滚动。

本次更新保留便携目录的 `config` 配置和已有文件。分发 ZIP 使用独立的中文默认配置，不复制本机的最近文件或个人设置。定制版原有开发构建提示仍保留。

## 快捷保存软件账号

1. 保持 KeePassXC 运行并打开密码库，选择普通分组。
2. 切换到需要保存账号的软件，按 `Ctrl+Alt+S`。
3. 若密码库锁定，先解锁；取消解锁不会创建条目。
4. 在原有条目编辑器中填写账号、密码、网址和备注，窗口标题会作为名称并建立精确窗口关联。
5. 点击确定后才添加条目；取消不添加。需要修改关联时在条目的自动输入页面编辑。

“工具 → 快捷保存热键”可修改或禁用热键。热键占用时会提示；修改失败保留原有有效热键。编辑或设置未结束时先结束当前操作。

## 快捷填充

在软件账号输入框中按 `Ctrl+Alt+A`，选择条目后输入。默认序列只输入账号、Tab、密码，不按 Enter。只有密码或账号的普通条目也默认不按 Enter。旧库中用户明确设置的输入序列仍保留，需要时自行删除序列里的 `{ENTER}`。

窗口标题变化时可能无法精确匹配，可手动选择条目或编辑关联。窗口标题不是应用身份验证；填充前确认软件和窗口，不向不可信界面填充。普通权限进程不能保证填充管理员窗口。

## Edge / Chrome

通过 KeePassXC 官方扩展页面安装 KeePassXC-Browser；在桌面“工具 → 设置 → 浏览器集成”启用对应浏览器，在扩展中连接密码库并确认配对。使用扩展现有的填充、新增保存和密码更新提示。

体验 LocalVault 定制弹窗时，完整解压项目发布的 Chromium 扩展 ZIP。在 `chrome://extensions` 或 `edge://extensions` 打开开发者模式，选择“加载已解压的扩展程序”，指向包含 `manifest.json` 的目录。复制这个扩展的 32 位 ID，在 LocalVault 的“工具 → 设置 → 浏览器集成 → 高级 → 自定义扩展 ID”粘贴，启用正在使用的浏览器并保存。打开密码库，通过该扩展发起连接，在桌面端检查并确认配对。移除定制扩展时，在同一设置里清空 ID，再保存。

浏览器扩展默认不自动提交。请勿同时打开原版和定制版 KeePassXC，以免 Native Messaging 注册指向另一个程序。便携目录移动后可能需要重新启用浏览器集成。开发者模式加载本地扩展只用于测试，日常优先使用官方商店版本。

手动同步步骤见《安卓设置与同步》。合并前使用“数据库 → 保存备份”。密码库主密码遗失无法由本项目找回。
